# Air Canvas

Air Canvas lets you draw in 3D space with the iPhone rear camera. Your finished drawing and the movement used to create it can be replayed together, then exported as a silent vertical MP4.

This repository contains the iOS app source and the public support documents. It does not contain private artwork, camera recordings, credentials, signing files, or the child-focused prototype.

## Build

Open `src/AirCanvas.xcodeproj` in Xcode, select your Apple Developer Team, connect an ARKit-capable iPhone running iOS 18 or later, and run. Camera drawing cannot be tested in the simulator.
